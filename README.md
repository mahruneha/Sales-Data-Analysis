# Sales Data Analysis

**Author:** Mahru Afrin Neha  
**Department:** Information Technology & Management

## Project Overview

This is a beginner-level sales data analysis project created for a GitHub portfolio. The project uses a sample sales dataset to explore revenue trends, product performance, category performance, and regional sales.

## Objectives

- Analyze overall sales performance
- Understand monthly revenue trends
- Identify high-revenue products
- Compare sales across categories
- Compare sales across regions
- Practice data analysis and visualization using Python

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- GitHub

## Project Files

| File | Description |
|---|---|
| `sales_data.csv` | Sample sales dataset |
| `sales_analysis.ipynb` | Jupyter Notebook containing the analysis |
| `images/` | Charts generated from the analysis |
| `README.md` | Project documentation |

## Sample Results

The sample dataset contains **240 sales transactions**.

- Total revenue: **$288,345.87**
- Highest-revenue product: **Laptop**
- Highest-revenue category: **Electronics**
- Highest-revenue region: **Khulna**

> These results are based on the sample dataset included in this educational project.
